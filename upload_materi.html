Migrasi Data Pelajaran dari Excel ke Firebase

Pastikan Anda telah mengisi firebaseConfig di dalam kode file HTML ini sebelum menggunakannya.

  1. Buka Spreadsheet/Excel Anda.
  2. Copy data dari kolom id, Pelajaran, Judul, dan Type (jangan copy baris headernya/judul kolomnya, cukup isinya saja).
  3. Paste ke dalam kotak di bawah ini. Pastikan jarak antar kolom rapi (terpisahkan oleh tab otomatis dari Excel).
  4. Klik Upload ke Firebase.
