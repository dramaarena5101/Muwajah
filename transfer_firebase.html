Muwajah System

Transfer data dari Firebase Lama + Penggabungan Materi Baru Semester 2 ke Firebase Baru (muwajah-5101).

Sumber: muwajah-5ed1d + Semester 2
Tujuan: muwajah-5101
PENTING: Aturan Keamanan (Security Rules) Firebase Baru
Agar script dapat membaca & menulis ke Firebase Baru (muwajah-5101), pastikan Firestore Security Rules diatur untuk mengizinkan akses:
  1. Buka Firebase Console > Firestore > Tab Rules
  2. Ubah kode aturan menjadi seperti ini:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
  • Klik tombol "Publish" (Publikasikan).
